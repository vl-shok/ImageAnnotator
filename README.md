# ImageAnnotator

Инженерный редактор пометок на фотографиях плат, узлов и изделий.

## Запуск
* **ImageAnnotator.exe** — готовая программа, Python не нужен. Собрать заново: `build_exe.bat`
  (результат — `dist\ImageAnnotator.exe`);
* двойной клик по **ImageAnnotator.bat** (или `python main.py [фото|проект.iap]`);
* если не хватает библиотек — один раз запустить **install_requirements.bat** (PySide6, numpy).

## Основной сценарий
1. Открыть фото: `Ctrl+O`, перетащить файл в окно или вставить скриншот `Ctrl+V`.
2. Выбрать инструмент слева (или клавишей): `A` стрелка, `R` прямоугольник, `T` текст,
   `C` выноска, `N` номер, `L` линия, `E` эллипс, `P` полилиния, `G` полигон, `F` карандаш,
   `M` выделение области фото, `K` обрезка / размер холста, `V` выбор.
   Короткий клик ПКМ или Esc во время рисования — завершить и перейти к «Выбору».
3. Свойства выбранного объекта — справа. Последний использованный стиль запоминается
   для следующих объектов. Можно выделить несколько объектов и поменять цвет всем сразу.
4. `Ctrl+S` — проект (*.iap, всё остаётся редактируемым), `Ctrl+E` — экспорт PNG/JPG/PDF,
   `Ctrl+Shift+E` — быстрый PNG рядом с фото, `Ctrl+Shift+C` — результат в буфер обмена.

## Навигация 
* колесо — масштаб относительно курсора; ПКМ + движение — панорама;
  СКМ + движение вверх/вниз — масштаб; `Ctrl+0` — вписать, `Ctrl+1` — 100%;
* короткий клик ПКМ — контекстное меню.

## Слои 
* «глаз» — видимость (Alt+клик — показать только этот слой), «замок» — блокировка;
* активный слой подсвечен — новые объекты попадают в него;
* перетаскивайте слои и объекты мышью; двойной клик по имени — переименовать;
* ползунок «Непрозр.» — прозрачность активного слоя;
* кнопки снизу: новый, дублировать, выше, ниже, объединить с нижним, удалить.
* Скрытые слои не экспортируются.

## Обрезка и холст (K)
* Тяните маркеры рамки; за пределы фото — холст увеличится (цвет нового места — справа).
* Shift — сохранить пропорции, Alt — от центра; Enter / двойной клик — применить.
* Если выбрано вставленное изображение — обрезается оно (неразрушающе, «Вернуть всё» в свойствах).

## Коррекция цвета
* Фото: `Ctrl+M`, меню «Изображение → Коррекция цвета…» или ПКМ по фото.
  Окно с ползунками (яркость, контраст, насыщенность, температура) и кривыми; изменения видны сразу.
  Насыщенность 0% — чёрно-белое. «Сбросить всё» — вернуть исходные цвета. Исходное фото не меняется.
* Вставленные изображения: выделите изображение — то же окно через «Изображение → Коррекция цвета…», Ctrl+M или ПКМ.
* Выделенная область фото: ПКМ → «Размытие по Гауссу…».

## Новые объекты
* `D` Размер: тяните от точки до точки; маркер надписи вдоль — положение текста, поперёк — отступ
  размерной линии. Стрелки наружу/внутрь, единицы (по умолчанию мм) и масштаб — в свойствах.
* `B` Разрыв цепи: проведите поперёк линии — две параллельные черты; маркер на черте меняет зазор;
  «Залить зазор» стирает линию.
* Выноска: Ctrl + тянуть от рамки блока — новая стрелка к другому объекту; ромб на рамке — начало стрелки, круг в центре — сдвинуть блок (стрелки остаются на месте), двойной клик по острию — удалить стрелку.
* Линия, стрелка и указатель выноски: средняя ручка изгибает дугой (двойной клик по ней — выпрямить).
* Приклеивание (магнит): если конец линии, стрелки, полилинии, размера или острие выноски/номера
  поставлен привязкой на точку другого объекта, он приклеивается (ручка зелёная) и едет следом,
  когда этот объект двигают, поворачивают или растягивают. Перетаскивание ручки конца двигает только
  саму линию: отпущен на точке объекта — приклеится к нему, в пустом месте — отклеится.
  Если сдвинуть линию целиком без объекта-цели, концы отклеиваются. Ctrl — рисовать без привязки.
* `Z` Выносной вид (лупа): выделите область фото — рядом появится её увеличение с линиями-выносками.
  Ручки: углы области, центр области (сдвиг области), центр вида (сдвиг вида), угол вида (увеличение).
  В свойствах — увеличение, форма (кнопки □ / ○, можно выбрать и до создания), цвет, линии-выноски.
* Карандаш: отпустите кнопку у начала линии — контур замкнётся, его можно залить.
* Текст: рамка, поворот (ручка ● сверху или «Угол поворота» в свойствах), кнопки **B** / *I*.

## Панели
* Над холстом во время действия появляется панель «Применить / Отменить».
* Кнопки «Привязки» и «Фильтр» сверху — выбор типов привязок и типов выделяемых объектов.
* В панели «Слои»: выделите несколько объектов, ПКМ → «Сгруппировать».
* Кнопка копирования сверху (`Ctrl+Shift+C`) — вся картинка с пометками в буфер (PNG без потерь).

## Полезное
* Shift при рисовании — угол 0/45/90°, квадрат/круг.
* Shift + перетаскивание ручки — переместить объект(ы) за эту точку с привязкой (Snap).
* Рамка слева направо — выбор объектов целиком внутри, справа налево — всё, что пересекает.
* `Shift+S` — привязка вкл/выкл. Фильтры привязки и выделения — справа, когда ничего не выбрано.
* Прямоугольник/эллипс: ручка ● сверху — поворот (Shift — шаг 15°), угол — в свойствах.
  Эллипс рисуется от центра; Alt при перетаскивании ручки — масштаб от центра.
* Полилиния/полигон: ручки «+» на сегментах — добавить вершину; удалить — двойной клик по вершине
  или ПКМ по вершине → «Удалить вершину».
* `Ctrl+Alt+G` (меню «Инструменты») — менеджер групп (снять галочку → объект выходит из группы).
* `Ctrl+G` группа, `Ctrl+L` блокировка, `Ctrl+]`/`Ctrl+[` порядок, стрелки — сдвиг,
  `Пробел` / `Shift+Пробел` — поворот выделенного на 45° по / против часовой стрелки.
* Меню «Изображение»: заливка/прозрачность/размытие/обрезка области, «область → объект».
* `F1` — список горячих клавиш.

## Структура кода
```
main.py                 запуск
annotator/
  items/                объекты-аннотации (общий базовый класс, handles, snap points, сериализация)
  document.py           документ: фон, слои, объекты, формат проекта (format_version)
  editor.py             все редактирующие операции + Undo/Redo (QUndoStack)
  commands.py           команды Undo
  selection.py          выделение + фильтр выделения
  snap.py               привязки
  canvas.py             холст: навигация, hit-testing, hover, ручки, индикаторы
  tools/                инструменты (выбор, рисование, выделение области)
  ui/                   панели свойств и слоёв, виджеты, иконки, тема, диалоги
  export.py             экспорт PNG/JPG/PDF, печать
tests/                  тесты логики (python -m pytest tests)
```
